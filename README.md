# 学校运动会秩序册与决赛编排系统

Windows 单机离线工具，用于配置并导出初高中分类报名表、导入报名表和竞赛日程、生成秩序册、录入成绩并生成决赛名单。

这是完整功能的公开脱敏版：保留程序、测试与构建脚本，内置姓名、静态章节和校纪录已替换为匿名或虚构示例。不含任何正式报名表、成绩、项目数据库、内部交接文件或个人电脑路径。正式使用前必须填写本校规程、工作人员和真实校纪录。

## 普通用户快速开始

本软件适合由体育老师在 Windows 电脑上离线使用。报名和成绩保存在本机项目文件中，不需要将学生数据上传到网站。

### 安装与运行

- **直接下载程序**：[Windows 公开版 v0.1.36](https://github.com/sylvvester/sport-meeting-booklet/releases/tag/v0.1.36-public)，打开页面后下载 Assets 中的 `sport-meeting-booklet-v0.1.36-public.exe`。
- **下载源码**：仓库首页点击 `Code → Download ZIP`。开发者按下方步骤安装 Python 3.12 或更高版本后运行。
- 如果项目的 Releases 页面提供 Windows 程序，下载对应版本的 `.exe`，放到固定文件夹后双击运行，不需要安装 Python。
- 如果没有已发布的程序，请使用下面的“开发运行”或“构建 Windows 开发包”步骤，从源码运行或打包。
- 完整秩序册导出为 `.docx`，请用 Word 或 WPS 打开，打印前预览分页。
- 决赛材料和成绩排名表的 PDF 导出依赖本机 Word/WPS 自动化接口；未安装或接口不兼容时，请先导出 DOCX。

### 从报名到秩序册

1. **项目首页**：新建运动会项目，保存为 `.sportsmeet` 文件，选择开始和结束日期并保存。软件下次启动会尝试打开上次使用的项目。
2. **报名表设置**：分别设置初中、高中以及男、女生可报名的项目。检查系统建议的赛制，选择“预决赛（一次比完）”或“预赛＋决赛（分两次）”，然后保存。
3. **发放报名模板**：分别导出初中和高中 Excel 模板。老师填写姓名、性别、年级、班级及最多两个个人项目，运动员号码无需填写。
4. **批量报名**：选择多个报名表，或导入文件夹内全部报名表。建议每班独立保存，并使用明确的年级班级文件名，例如“高一11班.xlsx”；一个年级共用一张表时，请逐行填写正确班级。
5. **校对修正**：导出核对报告，按报告中的来源文件、工作表和 Excel 行号检查。阻断问题必须先解决；自动修正和警告也应人工审阅，特别是同名学生、班级归属和项目简写。
6. **项目与日程**：生成标准日程模板，确认人数、组数、日期和时间，按学校场地及裁判安排修改 Excel，再导入比赛日程。自动生成的是建议日程，不是已经批准的正式赛程。
7. **抽签编排**：完成全项目校验后生成分组。正式使用后不要随意重新抽签，以免已打印分组与系统不一致。
8. **生成秩序册**：打开“编辑封面与静态章节”，填写本届开幕式、组委会、裁判名单、规程和校纪录，保存到项目，再生成完整秩序册 DOCX。
9. **打印前复核**：在 Word/WPS 中检查封面届次、目录、日期、项目人数、分组、姓名是否完整以及分页位置。公开版的默认文本仅是示例，必须替换成学校自己的内容。

### 比赛现场：成绩、晋级和排名

1. 进入“成绩录入”，选择对应预赛项目，检查单位（秒、分、米或个）后输入成绩。
2. 从 Excel 批量粘贴时，只复制一列成绩，点击成绩列的起始单元格后粘贴；粘贴顺序必须与当前运动员顺序一致。
3. 分钟成绩按“分:秒:百分秒”理解，例如 `1:53:29` 表示 1 分 53 秒 29；秒成绩的 `59:32` 表示 59 秒 32。保存前核对界面显示，勿把秒与分钟混用。
4. 不录成绩、只确定名次时，开启“手动决定名次”，依次点击运动员所在行，系统按各组分别赋予第 1、2、3 名。需要重排时使用“清除手动名次”。
5. 点击“保存成绩并生成决赛名单”，在“决赛材料”页查看名单及径赛道次，并导出裁判使用的材料。
6. 录入并保存决赛成绩，再生成成绩排名表。当前排名表输出前八名；同成绩按并列名次占位跳号。

### 重要限制与备份

- `.sportsmeet` 是项目数据库，不要手工编辑，也不要在两个程序中同时打开同一项目。
- 项目有自动备份，但默认只保留最近 10 份；重要修改、重新导入日程或重新抽签前，请额外复制项目文件到独立备份位置。
- 重新导入日程可能清空已有抽签、成绩和晋级数据；比赛开始后不要把它当作修改单条比赛时间的工具。
- 修改源报名表后应重新导入；确认无误后再生成日程和秩序册。
- 集体项目可以配置队数和日程，但当前尚不自动生成具体参赛队员名单/队伍分组表，请另行准备并核对。
- “某班报名人数偏少”、年级两端完全漏交的班级等情况不能仅依靠系统发现，需要与学校班级清单人工对账。
- 请勿在公开 Issues、截图或示例文件中上传真实学生姓名、报名表、成绩或项目数据库。报告问题时使用匿名数据，并说明软件版本、操作步骤和错误提示。

当前开发阶段首先固化可复现的编排与晋级规则。业务代码位于 `src/sport_meeting/core`，不依赖桌面界面。

## 开发运行

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -m pytest
sport-meeting
```

## 构建 Windows 开发包

```powershell
powershell -ExecutionPolicy Bypass -File packaging/build.ps1
```

生成文件为 `outputs/运动会秩序册系统-v0.1.36.exe`。构建脚本会先运行测试，再在最小化 Windows PATH 下执行界面启动自检；任一步失败都不会报告构建成功。

v0.1.36 汇总了第十一届运动会现场使用后的版面修正：

- **封面保留但不标页码，页码从目录页重新按 1 开始**（封面单独分节，`pgNumType` 在该节重启）。
- **竞赛日程与竞赛分组表统一为“日期时段 → 径赛 / 田赛 / 集体项目 → 项目”三级结构**，两章结构一致；时段标题统一为 `10月20日（星期二） 上午` 形式。
- **竞赛规程末尾的落款（校运会组委会 / 年月）自动右对齐**。
- 集体项目与教工项目的标题不再被单独留在页尾（`keep_with_next` 修正），消除由新增赛事触发的空白页。
- 裁判员名单等紧凑章节行距收紧，避免只溢出两行而多出一页。
- 可按需关闭封面（`render_full_booklet(..., include_cover=False)`），此时目录页即第 1 页。

v0.1.35 更新了整册 Word 排版：统一黑色标题与职务加粗，日程按日期、上午/下午和比赛类型分块，时间列只显示比赛时刻。表格支持跨页重复表头，备注与前文保持连排，常规班级代表队名单整块排版，封面以外显示页码。静态章节的重复全称仅在导出时隐藏，不改动保存的原文；最终分页仍需在 Word/WPS 中预览。

当前界面支持报名模板配置、报名与日程导入、核对、抽签编排、整册 DOCX 生成、成绩录入、决赛材料及现场材料包导出。

项目首页可用日历选择运动会开始和结束日期。标准日程模板会把报名表设置中的项目展开到各年级，按往届赛程的顺序、场地并行关系、实际人数和组数生成建议时间；没有报名数据时人数和组数留空。

两天赛程会把 200 米预赛安排在第二天上午、决赛安排在第二天下午；50 米、100 米、200 米从最后一组预赛结束到决赛开始至少间隔 45 分钟。400 米只在上午安排预赛、同日下午安排决赛，项目较多时自动分摊到两个比赛日。拔河现场只生成各年级 2 队冠亚军赛，第二天 9:30 起按初中、高中两个场地并行完成。径赛与田赛允许并行，并优先让各比赛日的结束时间保持接近。

公开版新建项目默认使用虚构的校纪录示例。请在“生成秩序册”→“编辑封面与静态章节”中填写本校真实校纪录并保存。“载入最新校纪录”会载入随公开版附带的虚构示例，不会联网取得本校纪录，请不要误用到正式比赛。

报名表中的号码列不作为导入依据。无论老师是否填写号码，软件都会按年级、班级和性别规则统一重编；被忽略的自编号码会在核对报告中逐行列出来源文件、工作表、Excel 行号、原号码和新号码。批量导入还会按同一年级已出现的最小至最大班号检查中间漏班，并以警告列入核对报告。

报名项目会结合当前项目设置进行归一化和合法性检查：例如初中“跳绳/跳远”和径赛数字简写会转换为对应标准项目；无法归属的项目阻止导入。填写姓名但没有有效项目的行会列入核对报告并从有效运动员名单排除。文件夹导入会保存源文件哈希，源报名表后续发生新增、修改或删除时，系统会要求重新导入后才能生成日程、抽签或秩序册。
